
# AI Usage Log – SpendSmart

Our team used ChatGPT as an AI assistance tool during the development of SpendSmart. We used it to understand coding concepts, plan the application structure, review code and troubleshoot issues.

| Tool | What we used it for | What it got wrong / what we fixed |
|---|---|---|
| ChatGPT | Discussing project requirements and dividing frontend and JavaScript responsibilities between team members. | The initial plan needed to be narrowed down to three main features. We finalized expense management, total calculation and category-wise spending as our MVP. |
| ChatGPT | Getting reference code and explanations for HTML structure, CSS styling and JavaScript expense management. | The initial JavaScript code used plain text for the empty expense message, so the CSS empty-message styling was not applied. We identified this during code review and improved the empty-state display. |
| ChatGPT | Understanding JavaScript arrays, event listeners, functions and Local Storage. | The initial category calculation repeated the grand-total calculation inside the category loop. We reviewed the logic and optimized it by calculating the grand total once. |
| ChatGPT | Suggesting testing scenarios for adding, deleting and saving expenses. | AI-generated code was not treated as automatically correct. We tested the features in the browser and checked the results before accepting the implementation. |

## How We Used AI Responsibly

- We used AI suggestions as references and reviewed the code before using them.
- We divided the work according to our team roles.
- We tested the application using sample expenses.
- We checked expense calculations, deletion and Local Storage.
- We are learning the code so that both team members can explain their contributions.
